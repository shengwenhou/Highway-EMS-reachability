# Highway-EMS-reachability

台灣國道（國道 1、2、3、3甲、4、5、6、8、10 號）每一公里路段若發生事故，要回答兩個問題：

1. **反應**：最近的消防分隊派救護車開過去，要多遠、要多久？
2. **送醫**：從事故點送到最近的**重度級急救責任醫院**，要多遠、要多久？

產出檔案：

- 互動地圖：`output/index.html`，可切換四種指標和行車方向，點選路段可看最近的分隊與醫院
- 靜態地圖：`output/map_distance.png`、`output/map_time.png`（反應），`output/map_hospital_distance.png`、`output/map_hospital_time.png`（送醫）
- 每公里路段結果：`output/segments.csv`
- 各指標的最遠點位排行：`output/farthest_points.csv`

這份結果有兩個明顯的熱點：

- **國道 6 號全線**：埔里一帶沒有重度級醫院，全線都要送到南投市的衛福部南投醫院。東行車道還得先開到下一個出口，所以東行比西行更遠。
- **嘉義、台南交界**：包括國 3 水上系統以南、國 1 嘉義系統到新營之間，以及國 3 烏山頭以北。這一帶交流道間距大，最近的重度級醫院（嘉基、嘉義長庚、奇美）又都離國道有一段距離。

## 方法

1. **路網**：OpenStreetMap（BBBike 每日擷取 `asia-south-china`，2026-10-14），切出台灣本島，納入國道到巷弄（motorway … residential, living_street），共 187 萬個節點、365 萬條有向邊。
2. **方向與路口**：遵守單行道、匝道方向（巷弄除外）。國道上的點只能沿同一方向車道抵達，所以救護車必須經由上游交流道或系統交流道進入。不跨越中央分隔島，也不使用緊急出入口。
3. **消防分隊**：內政部消防署「救援與應變單位點位」（data.gov.tw #5969）。保留外勤分隊與中隊共 617 處，排除局本部、大隊部、特搜／特種救助單位與外島。原始資料有 6 處座標為 0，已依地址補上。分隊位置吸附到最近的一般道路節點，國道與匝道除外。不限縣市。
4. **速度**：採 OSM 速限，未標示時依道路等級給預設值（國道 100、快速道路 80、省道 60、縣道 50、市區 30–40 km/h）。不考慮塞車，也不含出勤準備時間。
5. **重度級急救責任醫院**：衛福部「急救責任醫院分區名單」（更新日 115/4/29）中評為重度級的 54 家（`data/heavy_er_hospitals.csv`）。其中臺大、新竹馬偕、中國醫大三家是和兒童醫院合併評定，以成人醫院本院定位。座標以 OSM Nominatim 查詢，查不到或只對到公車站的 16 家，改用 OSM 醫院範圍的中心點。不限縣市。
6. **計算**：
   - 反應：以所有分隊為起點跑多源 Dijkstra。
   - 送醫：在反向圖上以所有醫院為起點跑多源 Dijkstra，得到每個節點到最近醫院的成本；傷患必須沿同方向車道開到下一個出口。
   - 兩者都把距離最短和時間最短分開計算，所以可能對到不同的分隊或醫院。
   - 每條國道每個方向的車道每 100 m 取樣一次，再依官方里程切成 1 km 一段，每段取**最差點**的值。
7. **里程**：OSM 交流道編號就是里程，用它來內插，誤差約 ±1 km。五楊、汐五高架的里程沿用平行主線。

### 已知限制

- 結果取決於 OSM 匝道資料的完整度，排名前幾的點位建議人工核對匝道配置。
- 國道 2 甲在 OSM 中只有零星路段標為國道，沒有納入。
- 沒有考慮實際派遣規則，例如轄區分工、國道專責救護分隊，以及部分分隊是否配置救護車。
- 國道3 南下 300–311K：OSM 中白河交流道只有北上出口和南下入口，找不到南下出口，所以南下傷患要開到柳營才能下交流道。如果白河實際有南下出口，這一段的送醫距離會明顯縮短，需要人工核對。
- 送醫只算一般道路車程，不考慮直升機後送、醫院當下的收治能量，也不含現場處置時間。

## 重現

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # 另需 apt install osmium-tool
.venv/bin/python scripts/01_fetch_osm.py      # 下載 OSM（約 2.2 GB）並切出台灣道路
.venv/bin/python scripts/02_fire_stations.py  # 消防分隊清單 → data/fire_stations.csv
# data/heavy_er_hospitals.csv 為人工整理自衛福部名單（見「方法」第 5 點），直接隨 repo 提供
.venv/bin/python scripts/03_route.py          # 建圖、路徑計算 → data/processed/
.venv/bin/python scripts/04_maps.py           # 地圖與表格 → output/
```

縣市底圖來自 npm 套件 [`taiwan-atlas`](https://www.npmjs.com/package/taiwan-atlas)，由 `01_fetch_osm.py` 一併下載。
