# Highway-EMS-reachability

台灣國道（國道 1、2、3、3甲、4、5、6、8、10 號）每一公里路段，若發生事故，**最近的消防分隊派救護車開過去要多遠、要多久**。

- 互動地圖：`output/index.html`（可切換反應距離／反應時間、行車方向，點路段看最近分隊）
- 靜態地圖：`output/map_distance.png`、`output/map_time.png`
- 每公里路段結果：`output/segments.csv`
- 最遠點位排行：`output/farthest_points.csv`

## 方法

1. **路網**：OpenStreetMap（BBBike 每日擷取 `asia-south-china`，2026-10-14），切出台灣本島，納入國道到巷弄（motorway … residential, living_street），共 187 萬個節點、365 萬條有向邊。
2. **方向與路口**：遵守單行道、匝道方向（巷弄除外）。國道上的點只能沿同一方向車道抵達，所以救護車必須經由上游交流道或系統交流道進入。不跨越中央分隔島，也不使用緊急出入口。
3. **消防分隊**：內政部消防署「救援與應變單位點位」（data.gov.tw #5969）。保留外勤分隊與中隊共 617 處，排除局本部、大隊部、特搜／特種救助單位與外島。原始資料有 6 處座標為 0，已依地址補上。分隊位置吸附到最近的一般道路節點，國道與匝道除外。不限縣市。
4. **速度**：採 OSM 速限，未標示時依道路等級給預設值（國道 100、快速道路 80、省道 60、縣道 50、市區 30–40 km/h）。不考慮塞車，也不含出勤準備時間。
5. **計算**：以所有分隊為起點跑多源 Dijkstra，距離最短與時間最短各算一次（兩者可能是不同分隊）。每條國道每個方向的車道每 100 m 取樣一次，再依官方里程切成 1 km 一段，每段取**最差點**的值。
6. **里程**：OSM 交流道編號就是里程，用它來內插，誤差約 ±1 km。五楊、汐五高架的里程沿用平行主線。

### 已知限制

- 結果取決於 OSM 匝道資料的完整度，排名前幾的點位建議人工核對匝道配置。
- 國道 2 甲在 OSM 中只有零星路段標為國道，沒有納入。
- 沒有考慮實際派遣規則，例如轄區分工、國道專責救護分隊，以及部分分隊是否配置救護車。

## 重現

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # 另需 apt install osmium-tool
.venv/bin/python scripts/01_fetch_osm.py      # 下載 OSM（約 2.2 GB）並切出台灣道路
.venv/bin/python scripts/02_fire_stations.py  # 消防分隊清單 → data/fire_stations.csv
.venv/bin/python scripts/03_route.py          # 建圖、路徑計算 → data/processed/
.venv/bin/python scripts/04_maps.py           # 地圖與表格 → output/
```

縣市底圖來自 npm 套件 [`taiwan-atlas`](https://www.npmjs.com/package/taiwan-atlas)，由 `01_fetch_osm.py` 一併下載。
