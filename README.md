# Highway-EMS-reachability

台灣國道（國道 1、2、3、3甲、4、5、6、8、10 號）每一公里路段若發生事故，要回答兩個問題：

1. **反應**：最近的消防分隊派救護車開過去，要多遠、要多久？
2. **送醫**：從事故點送到最近的**重度級急救責任醫院**，要多遠、要多久？

產出檔案：

- 互動地圖：`output/index.html`，可切換六種模式和行車方向；內建**點位查詢**，可選國道、方向、公里數，或直接在地圖上點選
- 靜態地圖：
  - 反應：`output/map_distance.png`、`output/map_time.png`
  - 送醫：`output/map_hospital_distance.png`、`output/map_hospital_time.png`
  - 跨區救護：`output/map_cross_county.png`，標出由鄰近縣市分隊救護較近的路段，北上／東行與南下／西行用不同顏色
  - 救護風險：`output/map_risk.png`，救護車停在車道上時被後車追撞的風險（紅／黃／綠）
- 跨區救護路段清單：`output/cross_county_segments.csv`
- 救護風險紅色路段清單：`output/risk_red_stretches.csv`
- 汐五・五楊高架救護分工：`output/wuyang.html`（北上、南下各一張地圖與分段表），靜態圖 `output/map_wuyang_north.png`、`output/map_wuyang_south.png`，分段表 `output/wuyang_segments.csv`
- 冷知識圖卡：`output/trivia.html`，從資料挑出 14 件事，每則附位置示意圖，並可連到地圖查詢該點
- **所有點位資料**（見下方「點位資料」）：`output/points_100m.csv`、`output/sight_20m.csv`
- 每公里路段結果：`output/segments.csv`
- 各指標的最遠點位排行：`output/farthest_points.csv`

## 救護風險：停在車道上的救護車會不會被追撞

這張地圖評估：救護車停在車道上時，後方以 110 km/h 駛來的車輛，能不能及早看見它並煞停。

計算方式如下：

- 每 20 m 假設有一台救護車停在車道上，**往上游回看**，算出後方駕駛最遠能在多遠之外看見它，也就是「可用視距」。視線會在兩種情況下被擋住：
  - **平面彎道**：視線偏離車道中心超過 6 m，也就是超出路幅加路肩的範圍。
  - **縱坡坡頂**：駕駛眼高 1.08 m，看向救護車車身 1.0 m 的高度，如果中間的路面比這條視線高，就看不到。
- 和時速 110 km/h 所需的距離比較：
  - **紅**：可用視距小於停車視距。停車視距約 210–230 m，包含 2.5 秒反應時間和 3.4 m/s² 減速，並依縱坡修正，下坡需要更長。
  - **黃**：可用視距在停車視距與決策視距 335 m 之間。335 m 是 AASHTO 在 110 km/h、鄉區道路改變車道或速度時的決策視距。
  - **綠**：可用視距達 335 m 以上。
- 每 100 m 取最差點上色。

主線結果（每 100 m 一點，共 19,969 點）：紅 15%、黃 37%、綠 48%。紅色當中，52% 是被縱坡坡頂擋住，48% 是被平面彎道擋住。

## 點位查詢

互動地圖上方有查詢面板，可以用兩種方式查詢任一點：

1. **選擇**：選國道、方向，再輸入公里數。輸入不是數字，或超出該國道的範圍（例如國道 1 號南下為 0.0–373.8K）時，會提示可輸入的範圍。在五楊高架等平面與高架並行的路段，會請使用者選擇要查哪一條車道。
2. **點地圖**：按「在地圖上點選」，再點國道。程式會列出 600 m 內的車道，包含兩個方向，以及平面與高架，讓使用者確認方向。

查詢結果包括：
- 上游與下游最近的交流道
- **救護反應**：距離、時間、困難度百分位，以及最近分隊；若是跨區救護也會標示
- **送醫**：距離、時間、困難度百分位，以及最近的重度級醫院
- **救護風險**：本點的視距與分級，以及上游 2 公里到下游 1 公里的風險帶；風險帶內若有紅色路段，會提醒其位置與距離

所有結果都已預先算好，存在網頁裡（`points_100m.csv` 的精簡版），查詢時不需要伺服器運算，也不需要呼叫 AI。

- **國道 6 號全線**：埔里一帶沒有重度級醫院，全線都要送到南投市的衛福部南投醫院。東行車道還得先開到下一個出口，所以東行比西行更遠。
- **嘉義、台南交界**：包括國 3 白河到烏山頭之間、國 1 嘉義系統到新營之間，以及國 3 烏山頭以北。這一帶交流道間距大，最近的重度級醫院（嘉基、嘉義長庚、奇美）又都離國道有一段距離。

## 方法

1. **路網**：OpenStreetMap（BBBike 每日擷取 `asia-south-china`，2026-10-14），切出台灣本島，納入國道到巷弄（motorway … residential, living_street），共 187 萬個節點、365 萬條有向邊。
2. **方向與路口**：遵守單行道、匝道方向（巷弄除外）。國道上的點只能沿同一方向車道抵達，所以救護車必須經由上游交流道或系統交流道進入。不跨越中央分隔島，也不使用緊急出入口。
3. **消防分隊**：內政部消防署「救援與應變單位點位」（data.gov.tw #5969）。只保留外勤分隊共 564 處，排除局本部、大隊、中隊、特搜／特種救助單位、港區分隊與外島。大隊與中隊是指揮層級，不負責跑救護，所以排除（名稱帶有大隊、中隊字樣但本身是分隊的，例如「第二大隊大美分隊」，仍保留）。港區分隊共 9 個（基隆港西岸與東岸、臺北港、臺中港西碼頭／防風林／南堤／第一分隊、蘇澳港、花蓮港），負責港區、不出勤國道救護，所以排除。排除前後所有路段的結果都相同。原始資料有 6 處座標為 0，已依地址補上。分隊位置吸附到最近的一般道路節點，國道與匝道除外。不限縣市。
4. **速度**：採 OSM 速限，未標示時依道路等級給預設值（國道 100、快速道路 80、省道 60、縣道 50、市區 30–40 km/h）。不考慮塞車，也不含出勤準備時間。
5. **重度級急救責任醫院**：衛福部「急救責任醫院分區名單」（更新日 115/4/29）中評為重度級的 54 家（`data/heavy_er_hospitals.csv`）。其中臺大、新竹馬偕、中國醫大三家是和兒童醫院合併評定，以成人醫院本院定位。座標以 OSM Nominatim 查詢，查不到或只對到公車站的 16 家，改用 OSM 醫院範圍的中心點。不限縣市。
6. **計算**：
   - 反應：以所有分隊為起點跑多源 Dijkstra。
   - 送醫：在反向圖上以所有醫院為起點跑多源 Dijkstra，得到每個節點到最近醫院的成本；傷患必須沿同方向車道開到下一個出口。
   - 兩者都把距離最短和時間最短分開計算，所以可能對到不同的分隊或醫院。
   - 每條國道每個方向的車道每 100 m 取樣一次，再依官方里程切成 1 km 一段，每段取**最差點**的值。
7. **里程**：OSM 交流道編號就是里程，用它來內插，誤差約 ±1 km。五楊、汐五高架的里程沿用平行主線。

### 已知限制與待核對事項

結果完全取決於 OSM 的匝道資料。排名前面的點位，有好幾個取決於某個交流道只有部分方向的匝道。已經查核過的有：嶺口交流道（國 10，確為半套）、五楊高架北上入口（機場系統到五股之間確實沒有入口），以及白河交流道（國 3，OSM 把南下出口畫反了方向，已在 `scripts/03_route.py` 的 `ONEWAY_FIX` 修正）。查核結果、仍待確認的項目（例如坪林交流道的管制），以及資料與模型的其他不確定之處，都整理在 **[VERIFY.md](VERIFY.md)**。

可以用 `scripts/05_trace.py` 印出任何一段實際走的路線，逐段檢查方向和匝道。

## 發布到 GitHub Pages

`.github/workflows/pages.yml` 會把 `output/` 整個目錄部署到 GitHub Pages，網站首頁就是互動地圖 `index.html`，靜態圖和 CSV 也可以從網站直接下載。

- **觸發**：`main` 分支的 `output/` 有變動時會自動部署，也可以在 Actions 頁面手動執行「Deploy map to GitHub Pages」。
- **第一次使用**：到 repo 的 Settings → Pages → Build and deployment，把 Source 設為「GitHub Actions」。
- **私人 repo**：免費帳號的私人 repo 不能使用 Pages，需要改成公開 repo，或使用 GitHub Pro／Team 方案。另外要注意，就算 repo 是私人的，Pages 網站本身仍然是公開的。

python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # 另需 apt install osmium-tool

.venv/bin/python scripts/06_trivia.py         # 冷知識圖卡 → output/trivia.html
